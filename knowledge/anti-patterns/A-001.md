## 错误长这样

```css
.js-anim .anim{opacity:0}
```

```js
document.documentElement.classList.add('js-anim');
if(!window.gsap) return;
```

## 为什么错

CDN 不可达时脚本提前 return，隐藏类永远不移除。内容都在 DOM 里但全透明，
用户看到的是"只有外壳的空白页"——比没有动画严重得多。

## 改成

不写 CSS 预隐藏；初始态交给 `gsap.from()` 自己设置；
守卫写成 `if(!window.gsap || reduced) return;`——返回即安全出口，页面本来就是完整静态页。
