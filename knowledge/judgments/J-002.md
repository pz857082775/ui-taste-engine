## 规则
- B 端行业后台 → 侧栏 + 顶栏 + KPI 行 + 图表/表格（密度按行业上调）
- ERP → 顶部多页签 + 侧栏 + KPI + 订单表 + 消息中心
- 移动 C 端（电商/服务/政务）→ 渐变头 + 宫格 + Bento + 列表 + 吸底/tab
- 文旅/重图 → 全屏实景 + 玻璃条 + 白面板 + 榜单
- 出行/本地服务 → 列表 + 地图分屏 + sticky 结算
- 监控大屏 → 中心 3D + 环绕面板 + 深色发光

## 为什么
骨架决定了 80% 的可用性，视觉只是 20%。选错骨架，再美的配色也救不回来。

## 怎么用
在提示词第 4 段（布局骨架）第一条就写明骨架名称与来源，禁止"通用现代布局"这类空话。
