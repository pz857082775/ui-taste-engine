## 二、配色规律（实测提取）

### 2.1 三类主色分配

| 系统类型 | 主色 | 强调色 | 语义色 |
|---|---|---|---|
| B 端行业后台 | 蓝 `#2E7CF6` 一线 | 青绿 `#22B07D`、紫 `#7B5CFA` | 红=告警/紧急、橙=待办/立项、绿=正常/完成 |
| 移动端 C 端 | 品牌色（蓝/绿/橙） | 单一高饱和 | 红=价格/满减、橙=认证/促销 |
| 文旅 APP | 图片主导，蓝色辅助 | — | 红=秒杀价 |

**共性**：
- 背景一律浅灰蓝 `#F5F7FB` 一线，**从不使用纯白做大面积页面底**（白色只给卡片）
- 卡片白 + 1px 浅描边 + 极软阴影；深色系统（大屏）用青色发光描边替代阴影
- 强调色出现频次极低：一屏通常 3-6 处（主按钮、激活导航、关键数字、状态点）
- 语义色全部走"软底 + 深字"（12% 透明底 + 同色 800 档文字），**没有一处纯色块大色块**

### 2.2 深色大屏配色
- 底 `#071A2F` 一线深蓝（不是纯黑）
- 描边 `#1E4F7A` + 青色发光 `#35D6FF`（只描边，不铺面）
- 数据色：青蓝双色为主，橙色仅用于对比/告警
- 网格底纹透明度 ≤6%

## 三、布局规律（六种可复用骨架）

### 3.1 B 端后台（最常见）
```
200px 图标+文字侧栏（分组 + 激活主色软底）
56-64px 顶栏（搜索胶囊居中/靠左 + 铃铛 + 用户块）
内容：页头(标题 24 + 副标题 13) → KPI 4-6 卡 → 主图/表格 → 右栏（占比/公告/待办）
```
变体：**电力/监控类用 6-8 个 KPI** + 顶部横幅插画 + 告警分级列表（红/橙/黄/蓝四色）。

### 3.2 ERP 型
顶部**多页签**（系统首页 / 商品发布 / 留量列表 / 全部订单）+ 侧栏 + 单页内 KPI + 双折线 + 环形占比 + 最近订单表 + 消息中心 + 团队 TOP5。

### 3.3 移动端 C 端（电商/服务/政务）
```
180-220px 渐变头（品牌色 + 3D IP 形象 + 问候/搜索）
白面板上浮 16-20px 圆角，覆盖头部 20-40px（制造层叠）
10 项圆形/方圆形图标宫格（5 列 ×2 行，每项浅色软底 + 彩色图标）
Bento 卡片区（1 大 + 2-4 小）
列表/榜单
吸底 CTA 或底部 tab 4-5 项
```

### 3.4 文旅 APP
```
全屏实景 Hero（占屏 40-50%）+ 书法/艺术字标题 + 分页点
半透明玻璃条导航（5 图标：门票/民宿/美食/好物/出行）
白色圆角面板上浮，圆形图标宫格 10 项
Bento（地图/消费券/VR/活动日历）
榜单（TOP1 大图 + 2/3 小图）+ 限时秒杀（红价 + 划线价）
```

### 3.5 列表 + 地图分屏（出行/本地服务）
左 380-420px 列表（筛选 + 卡片）+ 右地图（价格气泡 marker），
卡片结构：图 200px 高 + 名称 + `$80/天` + 属性行（座位/变速箱/燃料）+ 收藏心。

### 3.6 可视化大屏
```
中心 3D 主视觉（等距场景/六边形数据中心）
环绕 6-8 个数据面板（左右各 3-4）
顶部 KPI 行（4-6 个）+ 时间
底部装饰边框/返回
```
**布局纪律**：主视觉占 40-50% 面积，数据面板不得压在主视觉上，四角留装饰空间。

## 四、排版层级（实测字号）

| 层级 | 后台 | 移动端 | 大屏 |
|---|---|---|---|
| Display | 24-28px/700 | 28-34px/800（渐变头欢迎语） | 32-40px/700 |
| 区块标题 | 15-16px/650 | 17-19px/700 | 18-20px/600 |
| 正文 | 13-14px/400 | 14-15px/400 | 14-16px/400 |
| 元信息 | 11.5-12.5px | 11-12px | 12-14px |
| 数字 | 26-28px/750 等宽 | 22-26px/750 | 28-40px/700 |

**共性**：
- 字号跨度 2.4-3 倍（28 / 16 / 13）
- 标题字重 700，正文 400，绝不用 600 做正文
- 数字全部等宽 + 单位小一号（`¥ 890.00` 中 ¥ 与小数位更小）
- 中文标题字距收紧（-0.01em），大屏标题加宽字距（+0.05em）营造科技感

## 六、动效线索（静态图可推断）

- 渐变头均有"光斑/云层"细节，静态即暗示**缓慢位移**（8s 级）
- IP 形象/3D 图标是**呼吸动画**的天然载体（2.8-4s）
- 卡片有轻微投影差（1px vs 8px），暗示 **hover 抬升**
- 榜单 TOP1 角标、秒杀倒计时 → **脉冲/红点**提示
- 大屏的发光描边与流动路径 → **流光动画**（3-5s 循环）
- 弹层/抽屉遍布（筛选、日期、地址切换）→ 需要 **300-400ms 展开 + 0.75 出**

## 七、可直接复用的 12 条规律

1. 页面底永远浅灰蓝，白色只给卡片——避免"一整墙白"
2. 一屏强调色 3-6 处，超出就降级为描边/文字
3. 语义色全部软底深字，禁止大色块
4. 移动端渐变头 180-220px + 白面板上浮 16-20px 圆角
5. 图标宫格固定 5 列 ×2 行，圆形软底 48-56px
6. KPI 卡数量按业务密度：常规 4，监控/行业 6-8
7. 数字等宽 + 单位小一号 + 环比箭头带颜色
8. 榜单 TOP1 必须视觉差异化（大图/角标）
9. 列表+地图分屏：列表 380-420px，地图 marker 带价格气泡
10. 详情页右栏 sticky 结算卡（明细 + 主 CTA）
11. 大屏：中心 3D 主视觉 + 环绕面板 + 青色发光描边 + 网格底纹 ≤6%
12. 页签与分段控件按端分工：后台用下划线页签，移动端用胶囊分段

## 八、参考图自身的缺陷（不要照抄）

用 `audit_contrast.py` 的同一套标准目测，这批参考图普遍存在：

| 问题 | 出现位置 | 我们的处理 |
|---|---|---|
| 次要文字过浅（≈`#8A919F` on `#F5F7FB`，约 3:1） | 几乎全部后台的元信息 | 统一改 `#4E5764` / `#5F6A7D` |
| 渐变头上白字对比不足 | 移动端欢迎语、大屏标题 | 加 scrim 或加深渐变端 |
| 全屏实景图上叠小字 | 文旅 Hero 的公告条 | 加 40% 黑 scrim 或改白底胶囊 |
| 状态色过多（红/橙/黄/绿/蓝同屏） | 电力告警面板 | 最多 3 档语义色 + 1 中性 |
| 大屏数字密集但无层级 | 部分大屏 KPI 区 | 主指标放大 1.5 倍，其余降为辅助 |
