# 意图翻译层（给不懂设计术语的人）

目标：用户说"高级一点、别那么土"，也能翻译成 AI 能执行的参数。
**原则：最多问 3 个问题，其余靠推断；每个模糊词必须落到旋钮值或令牌值。**

---

## 一、三个必问问题（只在真的缺料时问）

```
1. 这是给谁看的？（客户/员工/患者/年轻人/专业人士）
2. 你希望他们第一眼感觉是什么？（选一个：干净 / 温暖 / 高级 / 有活力 / 可信）
3. 有没有你喜欢的网站或截图？（没有就跳过，我按上面的答案定）
```

问完立刻开工。**不要问"你要什么字体""圆角多少"**——那是我的活。

---

## 二、模糊词 → 参数的翻译表

### 气质类

| 用户说 | 翻译成 | 旋钮 | 关键参数 |
|---|---|---|---|
| **高级感 / 贵气** | 低饱和 + 大留白 + 一个强调色 + 衬线或窄体标题 | CRAFT 8 / VARIANCE 6 | 背景 `#F7F5F2` 暖白；正文 `#2B2B2B`；强调色饱和度 ≤60%；区块留白 ≥120px；标题字距 -0.02em |
| **干净 / 简洁** | 极简留白 + 少装饰 | CRAFT 7 / DENSITY 3 | 全页 ≤3 种圆角；无渐变；分隔线最多 2 条；正文 17px/1.7 |
| **专业 / 靠谱** | 中性色 + 蓝或深绿 + 网格严谨 | CRAFT 8 / VARIANCE 4 | 90% 中性 + 1 主色；8pt 网格；表格化信息；圆角 8-12px 偏小 |
| **有活力 / 年轻** | 高饱和点缀 + 大圆角 + 动效多一档 | CRAFT 6 / MOTION 7 / VARIANCE 7 | 强调色饱和度 85%+；圆角 16-24px；允许 1 个渐变；动效 0.3-0.5s |
| **温暖 / 亲和** | 暖白 + 圆润 + 手作感 | CRAFT 7 / MOTION 4 | 背景 `#FAF7F0`；圆角 12-20px；字体用圆体或宋体；阴影柔和 |
| **科技感** | 深色 + 冷色 + 精细线条 | CRAFT 8 / MOTION 6 | 背景 `#0E1116`；主色青/蓝；1px 发丝线；发光仅 1 处 |
| **透气 / 有呼吸感** | 降密度 + 加行高 | DENSITY 3 | 正文行高 1.7-1.8；段间距 ≥1.5 倍行高；区块留白 +30% |
| **有设计感 / 别那么普通** | 加一个签名细节 + 版式破格 | VARIANCE 8 | 一处不对称或跨容器；自定义编号/marker；标题跨出栅格 10-20% |

### 具体抱怨类

| 用户说 | 真实问题 | 处方 |
|---|---|---|
| "太挤了" | 密度过高 | `DENSITY` -2；卡内 padding 20→28；列表行高 +8px |
| "太土了" | 配色脏或饱和过高 | 饱和度降 20%；色相家族 ≤2；强调色只留 1 个 |
| "太花" | 强调色超预算 | 强调色出现次数压到 ≤5；删渐变；图标统一线性 |
| "字看不清" | 对比度不足或字号太小 | 正文 ≥15px（移动 ≥16）；对比 ≥4.5:1；次要文字提亮一档 |
| "不像大厂做的" | 缺网格与对齐 | 8pt 网格；数字等宽；卡片等宽等高；边距统一 24 |
| "感觉假" | 数据不真实 / 装饰过多 | 数据可加总；删掉无信息装饰；加真实图片或真实界面片段 |
| "太像 AI 做的" | 命中 AI 视觉集群 | 对照 `anti-slop.md` 五类集群逐条排查，换掉默认组合 |

## 三、翻译输出格式（每次都要产出这张卡）

```
【意图解析】
原话："{用户原话}"
判断：{气质类型} ｜ 平台 {pc/h5/...} ｜ 页面 {营销页/后台/...}

【旋钮】
CRAFT 8 · MOTION 4 · DENSITY 3 · VARIANCE 6

【令牌关键值】
bg #F7F5F2 / ink #2B2B2B / accent #B8422E（仅主按钮）
radius 6/10/14 · 留白 120px · 正文 17px/1.7

【硬性禁止】
- 禁止紫蓝渐变、禁止图标卡片阵、禁止逐段 fade-up
- 强调色出现 ≤5 次

【一句话方向】
"暖白纸感 + 一个陶土色 CTA + 大字标题，安静但有记忆点。"
```

用户看到这张卡能确认"是不是我要的"，不用懂术语。

## 四、常见误译（要避免）

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| "高级感" → 全黑背景 | 黑 ≠ 高级，多数行业黑底显得廉价 | 低饱和 + 留白 + 精确排版 |
| "科技感" → 满屏发光 + 玻璃 | 2015 年的科幻 UI | 深色 + 细线 + 一个发光点 |
| "年轻" → 彩虹渐变 | 像促销页 | 一个高饱和强调 + 大圆角 + 活泼动效 |
| "简洁" → 删到什么都没有 | 变成单薄 | 删装饰但补字号、色彩场、真实图 |
| "专业" → 全用灰色 | 没有重点 | 中性为主 + 一处强主色 |
