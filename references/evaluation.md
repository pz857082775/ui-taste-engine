# 评估标准（怎么证明它真的变强了）

没有测量的"自我进化"等于自我安慰。这里给出可算的指标、可跑的回归、可对照的盲评。

---

## 一、结果指标（最重要的三个）

### 1.1 盲评胜率（Blind Win Rate）
同需求 → 旧规则生成 A 版、新规则生成 B 版 → 打乱顺序，不看标签，用三问判断：

```
Q1 哪一版更像人做的？
Q2 哪一版 3 秒能看懂？
Q3 哪一版删掉一个元素也不影响理解？
```

`胜率 = 新规则胜出题数 / 总题数`
- **及格 60%** ｜ **良好 75%** ｜ **优秀 85%+**
- 低于 50%：新规则无效，回滚

### 1.2 一次通过率（First-Pass Rate）
```
一次通过 = preflight 0 ERROR + 10 项验收条全过 + 用户零返工
一次通过率 = 一次通过任务数 / 总任务数
```
- 基线（无知识库）通常 30-40%
- **目标：6 个月内到 70%**

### 1.3 平均返工轮次（Rework Rounds）
```
返工轮次 = 用户提出修改的次数（不含自己主动打磨）
```
- **目标：从 3.2 轮降到 ≤1.5 轮**

## 二、过程指标（知识库健康度）

| 指标 | 算法 | 健康区间 |
|---|---|---|
| 知识卡总数 | `kb.py stats` | 稳定增长，月增 8-15 张 |
| 置信度分布 | conf≥4 占比 | 20-35%（过低=没沉淀，过高=过度自信） |
| **复用率** | 被 `use` 引用的卡 / 总卡 | ≥50% |
| 衰减率 | 近 90 天降级的卡 / 总卡 | 5-15%（过低=没淘汰，过高=记了太多垃圾） |
| 冲突数 | `check` 报告的冲突 | ≤3，且全部有裁决记录 |
| 孤儿卡 | 0 次复用且创建 >30 天 | <10% |

`kb.py stats` 直接输出这张表。

## 三、回归集（晋升闸门）

`evals/cases.yaml` 固定 10 个用例，覆盖四类页面 × 四端：

| # | 用例 | 类型 | 平台 | 重点考察 |
|---|---|---|---|---|
| 1 | SaaS 官网首页 | 营销页 | pc | 反 AI 脸、单一签名细节 |
| 2 | 咖啡品牌单页 | 营销页 | h5 | 移动原生化、字号可读 |
| 3 | 数据后台总览 | 数据工作台 | pc | KPI 卡、表格、图表 |
| 4 | 自媒体工作台首页 | 创作工作台 | pc | 待办 C 位、平台色 |
| 5 | 医疗工作台首页 | 服务型工作台 | pc | Hero 横幅、时间轴 |
| 6 | 电商订单列表 | 数据工作台 | pc | 表格密度、状态徽章 |
| 7 | 预约表单页 | 服务型 | h5 | 表单状态、热区 |
| 8 | 会员中心 | 通用 | miniapp | rpx、tabBar、分包意识 |
| 9 | 运动数据页 | 通用 | app | 安全区、暗色、手势 |
| 10 | 商品详情 | 电商 | h5 | 图文节奏、吸底栏 |

**晋升规则**：新规则上线前后各跑一遍 10 例，按 `review-rubric.md` 打分：
- 总分不下降 >2 分
- 无单例下降 >5 分
- 任一项不合格 → 拒绝晋升

## 四、专业度阶梯（判断"是否真的更专业"）

| 层级 | 表现 | 判定方式 |
|---|---|---|
| **L1 不难看** | 有基本层级、对齐、配色不脏 | 10 项验收条 ≥7 项通过 |
| **L2 有风格** | 能稳定产出指定气质，且不撞 AI 默认脸 | 反例库 0 命中 + 盲评 Q1 胜率 ≥60% |
| **L3 有判断** | 能解释"为什么这样设计"，并给出替代方案 | 评审输出包含"为什么 + 替代方案"，且被采纳 ≥70% |
| **L4 能预判** | 生成前就指出可能出问题的地方，并规避 | 预判问题被实际验证的比例 ≥70% |

**当前定位**：本引擎目标是让 L1→L2 稳定、L3 可复制，L4 靠长期积累（不承诺）。

---

## 五、盲评执行细节（防止自欺）

1. 两版必须**同需求、同平台、同内容**，只差被测试的那条规则
2. 截图统一尺寸、统一裁切（1440×900 或 390×844）
3. **不看自己的提示词**再评（先打乱文件名）
4. 至少 3 人评（自己 + 2 个非设计同事），取多数
5. 每季度做一次完整盲评（10 例 × 3 人）

```markdown
结论：通过 / 拒绝
回滚方式：改回 {文件} 的 {行/值}
```

## 七、一张图看懂"变强"的定义

```
更强的定义 =
  盲评胜率 ↑
  + 一次通过率 ↑
  + 返工轮次 ↓
  + 知识复用率 ↑
  + 回归集不掉分
```

**任何一项变差，都不能宣称"进化成功"。** 单一指标上涨（比如知识卡数量）毫无意义。
